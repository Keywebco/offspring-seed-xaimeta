Ring of Six — Standing Checklist

Status: PROPOSED, NOT CANON.

This checklist is the Stage 1 standing loop. Every task passes around the Ring of Six. No permanent chair. Circular. Human and AI partners sit at every station.

Station names are deferred. This checklist runs at each station in whatever order Roger defines.

---

What this checklist is

A mirror, not a gate. It is posted on new issues and new pull requests so the work can see itself before it moves. It blocks nothing. It approves nothing. It records what is present and names what is missing.

Effectful decisions do not stop at this checklist. If a task is effectful, this checklist escalates. The Twelve gate, and Roger's exact word, carry the decision.

---

One pass around the loop

At each station, run the checks below. A check is answered with one of: present, missing, not applicable, or unknown. "Unknown" is a valid answer and must be written down. Silence is not an answer.

Check 1 — Source present

Every factual claim in the work names its source. A claim with no source is not a fact. It is labeled accordingly, and the work says so plainly.

Answer: present / missing / not applicable / unknown.

Check 2 — Confidence stated

Every claim carries a confidence. Confidence is stated in plain words, not invented precision. If confidence cannot be stated, that is written down as unknown.

Answer: present / missing / not applicable / unknown.

Check 3 — Falsifier named

Every factual claim names what would show it to be wrong. A claim with no falsifier is not yet a fact. It is a belief, and it is labeled as one.

Answer: present / missing / not applicable / unknown.

Check 4 — Label applied

Every claim carries one label: FACT, INFERENCE, ASSUMPTION, or UNKNOWN. A claim with no label is returned as incomplete. No claim passes unlabeled.

Answer: present / missing / not applicable / unknown.

Check 5 — Kindness and consent

The work is checked for kindness, consent, accessibility, and clarity. No blame language. No pressure. No hidden ask. If the work touches a person, their consent is confirmed or the work waits.

Answer: present / missing / not applicable / unknown.

Check 6 — Escalation if effectful

The work is checked for effect. Effect means anything that changes something in the world outside the work itself: money, permissions, identity, public claims, deployment, deletion, legal or safety matters, irreversible change, or external communication.

If the work is effectful, this checklist does not proceed on its own. It escalates to the Twelve gate and waits for Roger's exact word. If the work is not effectful, the checklist notes that and moves on.

If there is doubt, treat the work as effectful and escalate.

Answer: not effectful / effectful, escalated / unknown, escalated.

---

Result of one pass

After one pass around the loop, the checklist reports:

- how many checks were present, missing, not applicable, or unknown
- which checks were missing, and what is needed to close them
- whether the work is effectful, and if so, that it has been escalated
- the date and time of the pass
- the name of the mind that ran the pass

A pass with any check "missing" is not a failure. It is a map. The work continues, and the map goes with it.

A pass with any check "unknown" is not a failure either. It is the truth, written down, which is the point.

---

What this checklist refuses

- It does not name the Ring of Six stations. Those are Roger's words.
- It does not approve effectful work. That waits for the Twelve gate and Roger's exact word.
- It does not block non-effectful work. It is a mirror.
- It does not speak as a mind. It reports.
- It does not modify itself. Changes go by PR, branch-first, for Pontus to review and Roger to approve.
